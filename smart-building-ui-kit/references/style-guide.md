## 1. 設計原則

中控系統的圖示跟行銷用 icon 不一樣，它有三個現實條件：

- **尺寸小**：設備卡片上一排十幾顆，每顆實際顯示 20～24px。
- **狀態多**：同一顆攝影機可能同時有「運轉／離線／警報」多種樣貌。
- **使用者是值班人員**：他要在一秒內掃過一整面牆，不是慢慢欣賞圖案。

所以整套規範圍繞三句話：**輪廓優先於細節、顏色由系統決定、一致性優先於單顆圖示好看**。

## 2. 格線與安全區

畫布固定 `viewBox="0 0 24 24"`。內容放在 **2～22** 的方格內（等於四邊各留 2px）。

為什麼是 2px：中控卡片上的圖示通常坐在 28～40px 的圓角底色塊上，貼邊會讓圖示和底色塊邊緣黏在一起，一整排看起來會忽大忽小。

常用 keyline（造型都往這幾個框靠，排在一起才會整齊）：

| 造型 | 範圍 |
|---|---|
| 正方形／方盒 | x, y = 2 → 22 |
| 圓形 | cx = cy = 12，r = 10 |
| 橫向矩形（面板、卡片、螢幕） | x 2→22、y 4→20 |
| 直向矩形（門口機、機櫃） | x 5→19 或 6→18、y 2→22 |
| 底座／地面線 | y = 21 |

## 3. 線條、圓角、對齊

| 項目 | 值 | 理由 |
|---|---|---|
| `stroke-width` | 2（全套統一；次要內部細節可用 1.5，但**同一顆圖示裡最多出現兩種，且整套一致**） | 混線寬是一排圖示看起來像拼裝的最大原因 |
| `stroke-linecap` | `round` | 尖角在深色底會出現灰點 |
| `stroke-linejoin` | `round` | 同上 |
| 方框圓角 | `rx="2"`（小板件 1.5～2.5） | 統一圓角是「同一家人」的視覺訊號 |
| 最小細節尺寸 | 3px（同時是兩個元素的最小間距 1.5～2px） | 低於 3px 的細節在 24px 會糊成一團 |
| 元素數量 | 盡量 ≤ 8 條路徑 | 超過就是訊號「這概念該簡化」 |

**對齊**：座標盡量落在整數或 0.5 的倍數。線寬 2 配上 x = 12 這種整數，線的邊會正好落在整數格上，縮放時最銳利；落在 x = 0.3 這種位置則會產生 1px 的灰邊。

## 4. 顏色與主題

圖示檔案裡**只准出現**這幾種顏色值：

- `currentColor`（主線條）
- `var(--icon-accent, currentColor)`（點綴，可省略）
- `none`（`fill`）

其餘（`#hex`、`rgb()`、`hsl()`、漸層）一律不准出現在圖示裡。這不是潔癖：中控專案幾乎一定會遇到「換品牌色」「深淺面板切換」「警報狀態變紅」三件事，寫死顏色的圖示在這三件事上都要重畫。

顏色權杖定義在 `assets/tokens.css`：

| 權杖 | 淺色介面 | 深色面板 | 用在哪 |
|---|---|---|---|
| `--icon-ink` | `#1F2A37` | `#E6EDF5` | 圖示主線條 |
| `--icon-ink-muted` | `#8FA3B8` | `#7C8EA3` | 未啟用、次要 |
| `--state-online` | `#30A46C` | 同 | 運轉正常 |
| `--state-active` | `#2AA9E0` | 同 | 選取中、操作中 |
| `--state-warning` | `#F5A524` | 同 | 注意、臨界 |
| `--state-alarm` | `#E5484D` | 同 | 警報、故障 |
| `--state-offline` | `#5A6B7D` | 同 | 離線、停用 |
| `--icon-accent` | `#2AA9E0` | 同 | 雙色圖示的點綴 |

深色面板上，狀態色請直接沿用（它們的亮度在 `#0A111B` 上仍夠亮），只換 `--icon-ink`。

## 5. 狀態的表達

**規則：圖示只回答「這是什麼設備」，顏色才回答「它現在怎麼樣」。**

理由很實際：如果每種狀態都要一顆圖示，八種設備乘五種狀態就是四十顆，之後加設備、改狀態色都得重畫；而用顏色表達，四十顆變八顆，值班人員也只需要學一套顏色語彙。

所以：

- 設備卡片、清單、拓樸圖上的「狀態」→ 改 `color`，不換 `src`
- 只有**圖例、報表、下拉選單**這種沒有顏色語意的地方，才使用 `sts-*` 圖示
- 需要狀態圓點時，**不要在圖示裡畫**。用 UI 層統一疊一個 `cx=19 cy=5 r=3` 的圓（外圈 1.5px 底色挖空），這樣一整排的點才會落在同一條線上；自己畫的話每顆圖示的點都會歪在不同位置。

## 6. 簡化決策

24px 塞不下細節是常態。處理順序：**砍元素 → 改造型 → 才考慮 `-dense` 變體**。

判斷方法：把圖示縮到 24px，瞇著眼看 0.5 秒——還認得出是什麼，過關；要靠細節才認得出來，就得換一個更能代表它的輪廓。

幾個實際例子：

| 概念 | 直覺畫法（失敗） | 改成 |
|---|---|---|
| 配電盤 | 箱子裡畫一堆斷路器與接線 | 一個箱子 + 一道閃電 |
| 車道閘門 | 畫一台車正在通過 | 機柱 + 斜 45° 的橫桿 |
| 訪客 | 人臉五官 | 人形輪廓 + 胸前識別證 |
| 撒水頭 | 真實的灑水頭結構 | 圓頂 + 兩顆水滴 |
| 建築 | 畫出窗格與樓層線 | 大樓輪廓 + 三排點狀窗 |
| 水表／電表 | 儀表上的刻度數字 | 圓盤 + 一根指針 + 水滴/閃電 |

如果一個概念要用三顆圖示才講得清楚，通常是概念切錯了——拆成兩顆不同設備，或改用「一顆圖示 + 狀態色」。

## 7. 常見錯誤對照表

| 錯誤 | 為什麼壞 | 改成 |
|---|---|---|
| 寫死 `#1F2A37` | 深色面板上幾乎看不見，換狀態色也失效 | `currentColor` + tokens |
| 用 `<text>` 寫「KM」「P」 | 面板不一定有這個字型，會變空白方塊 | 用線條畫，或拆成別的造型 |
| 混用 1.5 與 2 線寬 | 一排圖示像不同人畫的 | 全套 2 |
| 塞 20 條路徑 | 24px 糊成一團 | 砍到 ≤ 8 條 |
| 圖示貼到 `x=0` | 在底色塊上黏邊 | 留 2px |
| 每顆圖示各畫狀態點 | 點沒對齊，一排列看起來像故障 | UI 層統一疊 |
| 用漸層／`<filter>` 陰影 | 深色或淺色底一定有一邊難看，且匯出後更容易髒 | 純線條 |
| 一個 SVG 塞兩顆圖示 | 無法獨立取用、無法排版 | 一檔一圖示 |
| 檔名 `camera_final2.svg` | lint 不過，且半年後找不到 | `dev-camera-dome.svg` |
| 省略 `xmlns` | 用 `<img src>` 載入時部分環境不顯示 | 保留 `xmlns` |
| 大面積 `fill="currentColor"` | 深色底上變成一塊亮塊 | `fill="none"`，只用線條 |
| `width="24" height="24"` | 蓋掉 CSS 縮放，放大就破 | 只留 viewBox |

### 7.1 已實測證實的「誤讀地雷」

畫「撒水泵」時連續踩了好幾輪，才發現某些幾何組合會被讀成完全不同的東西——而且只有在真的算成 PNG 用眼睛看之後才會發現（腦袋裡想都會覺得很合理）。這張表是實際驗證過的結果：

| 你畫的 | 會被讀成 | 怎麼避開 |
|---|---|---|
| 圓形 + 內接向右三角（P&ID 泵浦符號） | **播放鍵** | 三角形不要正對右方；或改用非三角的符號 |
| 圓 + 三道放射短線（朝上張開） | 盆栽／發芽 | 水花不要從一個點放射 |
| 圓 + 向右擴散弧 | 喇叭／揚聲器 | 弧線是「聲音」的專屬語彙（用在 `dev-speaker`、`dev-access-reader`），不要拿來表示水 |
| 方框 + 內部圓（同圓心） | **攝影機鏡頭** | 圓要與方框某一邊相切（例如馬達貼住泵殼），不要放正中間 |
| 直立圓筒 + 底座 | 麥克風 | 立式設備要加接管或底座凸緣 |
| 橫桿 + 下方兩道短墨 | 水龍頭 | 撒水頭要加傘面／圓頂，不要只是光禿的橫桿 |
| 圓頂（或傘面）+ 斜下水花 | 雨傘／香菇 | 圓頂跳度不要超過接管寬的兩倍 |
| 方框 + 上方一滴水（用管線連接） | 水塔／水槽 | 水滴要靠近主體用「徒章」的方式呈現，不要用管線引到遠處 |

兩條正面結論：

1. **水滴是最可靠的水意符號。**在 24px 裡同時畫「泵浦」和「撒水動作」非常難，但畫「泵浦機身 + 一顆水滴徒章」就很容易讀。這是 HMI 圖示的常見做法：**主體負責說明「這是什麼」，徒章負責說明「屬於哪個系統」**。
2. **波浪線能有效表示水，但要緊貼主體。**浮在主體下方太遠，會變成手柄或底座；緊貼底部則讀成「水面」。

## 8. 座標小抄

常用座標值（整數或 .5 為主）：`2, 3, 4.5, 5, 6, 8, 9, 12, 15, 16, 18, 19, 19.5, 21, 22`

幾個直接可用的骨架：

```svg
<!-- 方盒類：門口機、機櫃、面板、卡片 -->
<rect x="4" y="2" width="16" height="20" rx="2"/>

<!-- 橫面板類：螢幕、讀頭、開關面板 -->
<rect x="2" y="5" width="20" height="14" rx="2"/>

<!-- 圓形類：表盤、風扇、燈 -->
<circle cx="12" cy="12" r="9"/>

<!-- 半球類：攝影機、感測器 -->
<path d="M5 13a7 7 0 0 1 14 0z"/> <!-- 上半圓，底部 y=13 -->

<!-- 底座／地面 -->
<path d="M3 21h18"/>

<!-- 聲波／感應弧（右側張開，弦長控制在 12 以內才不會超出畫布） -->
<path d="M17 9a4.5 4.5 0 0 1 0 6"/>
<path d="M19.5 6.5a8 8 0 0 1 0 11"/>
```
